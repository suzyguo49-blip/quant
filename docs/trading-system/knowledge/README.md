# 教材 / PDF / 操盘笔记

## 操盘笔记（推荐）

1. 把笔记全文粘贴进 **[操盘笔记.md](操盘笔记.md)**（`---原文开始---` 下方）
2. 在 Cursor 中说：

```text
@docs/trading-system/knowledge/操盘笔记.md
按 short-term-trading-evolution 入库到 playbooks/notes.md，
并更新 操盘笔记-映射表.md，与 theme.md 对照冲突。
先出草案，等我确认。
```

3. 确认后说 **「确认入库」**，规则进入 `playbooks/notes.md`（id：`N-001`…）

映射关系见：[操盘笔记-映射表.md](操盘笔记-映射表.md)

## 其他教材

将 PDF 转成 Markdown 后命名：`<书名>-summary.md`，同样用「入库」流程。
