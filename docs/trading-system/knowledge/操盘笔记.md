# 《操盘笔记》交易战法大全

*基于《操盘笔记（3.19更新）.pdf》完整提炼*

## 一、趋势跟踪与波段交易战法


| 战法名称              | 核心逻辑                                      | 关键量化/形态条件                                                                                                                     | 买卖点与风控要点                                                     |
| ----------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **趋势朱雀战法**        | 通过结构、角度和趋势线判断趋势的底部与顶部，进行顺势交易。             | **1号（判底）**：结构出现衰竭+背驰+角度缓和；价格有效突破下跌趋势线；出现强势K线反转。 **2号（判顶）**：结构出现衰竭+背驰+角度改变+下降趋势；价格有效跌破上升趋势线。                                   | **买点**：朱雀1号判底条件成立时。 **卖点**：朱雀2号判顶条件成立时，或结合基本面、题材分析。          |
| **玄武战法**          | 捕捉强势调整后的主升浪，遵循“上涨-回调-再起涨”的动力学模型。          | **1号**：AB段上涨>45度；BC段回调<45度；AB段放量；整体涨幅AB<50%。 **2号**：结构同1号；BC段放量约为AB段的50%，且大于地量。 **3号**：AC段为上升趋势，涨幅<50%；K1为强阳线+历史最大放量（突破前高为佳）。 | **买点**：1号/2号在C点企稳后；3号在K1或次日K2。 **卖点**：采用朱雀战法2号判断顶部。          |
| **遍地黄金三角形战法**     | 捕捉上涨中继形态（三角形整理）结束后的突破行情。                  | 1. 股价处于上涨途中，短期均线聚合后向上发散。 2. 形成对称三角形（上下边收敛）或上升三角形（上边平行，下边上倾）。 3. 三角形每条边至少有两个吻合的高低点，整理时间充足（K线数≥9）。                              | **买点**：放量突破三角形上边时。                                           |
| **静待花开均线粘合战法**    | 利用多周期均线高度粘合后选择方向的特征，捕捉变盘起涨点。              | 1. 5、10、20、60、120日等均线在狭窄区域高度粘合。 2. 股价处于中低位，属于热门板块。 3. 均线开始多头发散（10日>20日），成交量明显放大（5日均量>90日均量）。                                  | **买点**：均线由粘合转为多头发散，且量能配合时。                                   |
| **超跌回马枪战法**       | 在大盘超跌反弹的特殊环境下，筛选被错杀的活跃个股。                 | 1. 适用环境：上证指数ADR<0.6且向上拐头。 2. 使用软件指标“均线粘合2.0”在“风格板块-户数减少”中排序。 3. 选择“超跌值”小于-15的非ST股。                                            | **买点**：符合筛选条件，并结合个股技术形态。                                     |
| **潜龙在渊战法**        | “九五至尊战法”的互补策略，属于抄底模式，关注股价跌破“潜龙线”（黄线）后的机会。 | 1. 股价从高位下跌，下破“潜龙线”。 2. 结合筹码、量价判断底部区域。                                                                                         | **买点**：分批建仓。首次买入1/3仓，下跌10%再加1/3，以此类推。 **要点**：必须有耐心，需防范系统性风险。 |
| **博弈长阳战法**        | 通过“博弈K线”长度，辅助判断主力控盘度，用于筛选即将启动的强势股。        | 1. 博弈K线数值接近100。 2. 表明该价位获利盘比例极高，主力控盘力度强。                                                                                      | **作用**：不作为独立买点，用于辅助判断个股拉升潜力，预示爆发力度可能更强。                      |
| **出在主升高点（趋势/筹码）** | 通过趋势跟踪或筹码分布变化，尽可能持股到主升浪高点。                | **趋势角度**：上涨趋势不结束不出局，结合量价、乖离率、多周期判断顶部。 **筹码角度**：观察底部“建仓峰”是否锁定。只要建仓峰不缩短，行情未尽；建仓峰明显缩短且高位出现“出货峰”时警惕。                              | **核心**：在主力出货阶段持股，享受最快拉升段，但只卖不买，严格设置止盈保护线。                    |
| **龙回头战法**         | 捕捉前期龙头股经历一波调整后，开启第二波上涨的行情。                | 1. 前期是市场总龙头或核心人气股。 2. 回调过程缩量，在关键支撑位（如10日、20日均线，或前期筹码平台）企稳。 3. 出现放量阳线或涨停板等启动信号。                                                | **买点**：确认企稳并出现启动信号时。 **要点**：对市场地位和人气要求高。                     |
| **起爆K战法**         | 识别标志性的启动K线，抓住主升浪起点。                       | 1. 通常为一根放量的中阳线或大阳线。 2. 突破关键压力位（如平台、前高、重要均线）。 3. 带动短期均线系统形成多头排列。                                                               | **买点**：起爆K线出现当日或次日确认时。                                       |
| **蛟龙出海战法**        | 标志性K线形态，预示趋势发生强反转。                        | 1. 一根放量长阳线，同时上穿多根重要均线（如60日、120日线）。 2. 通常出现在长期盘整或下跌趋势的末端。                                                                      | **买点**：蛟龙出海形态确认时，是强烈的趋势反转做多信号。                               |


## 二、短线与涨停板交易战法


| 战法名称               | 核心逻辑                               | 关键量化/形态条件                                                                                                            | 买卖点与风控要点                                                                                |
| ------------------ | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **涨停白虎战法**         | 专注于涨停股，博弈其趋势的延续性。                  | 1. K1为涨停板。 2. 结构：涨停前有一段上涨（AB段），角度>45度。 3. 涨幅：AB段整体涨幅<30%。 4. 成交量：涨停日（K1）放量大于平均地量。                                    | **买点**：关注涨停板（K1）本身或次日的表现。                                                               |
| **暴力大阳擒涨停战法**      | 利用极端情绪反转，捕捉强势反包启动的涨停板。             | 1. 前一日为跌幅超过7%的大阴线。 2. 当日强势涨停，形成反包。 3. 位置：处于上涨初期（20天内涨幅不超过30%），常在30、60日均线附近。                                          | **买点**：反包涨停当日或次日开盘低吸。                                                                   |
| **蜻蜓点水短线战法**       | 捕捉次日高开强势反包前日阴线的短线机会。               | 1. 昨收阴线，跌幅≥2%（假阴线也可）。 2. 今高开在昨日阴线实体2/3以上位置。 3. 需结合开盘“选强七要素”综合判断（大盘/板块、高开幅度、盘子、股价、昨量、今量比、个股位置）。                       | **买点**：9:25-9:30，形态与盘口均符合则小仓介入。 **止盈**：当天不涨停则次日逢高卖；涨停则持有至次日不涨停卖。 **止损**：当天收阴则次日平开或低开止损。 |
| **空中飞仙暴利短线战法**     | 狙击平台突破或创新高突破的涨停板，追求主升浪。            | 1. **三维共振**：政策面（热点）+技术面（突破形态）+资金面（游资/机构）。 2. **形态**：低位或平台涨停突破，量价齐升突破前高。 3. **盘口**：高开2.5%-5%，量比大，分时在均价线上方运行等“开盘选强十点”。 | **买点**：符合形态，且开盘满足强势条件时买入。 **仓位**：轻仓（1成内）。 **止损**：买入当天不涨停，止损位设在前一涨停板一半的位置。               |
| **回头望月暴利短线战法**     | 通过龙虎榜数据，筛选有知名游资介入、回调缩量的强势股，博弈二波。   | 1. 有重大热点题材支撑。 2. 流通盘小（<10亿），股价低（启动时<10元）。 3. 启动后龙虎榜有知名游资身影。 4. 首轮大涨高位未爆量（未超前高量）。 5. 回调过程必须缩量。                        | **买点**：符合上述条件的个股回调缩量企稳后。                                                                |
| **打首板、抢首板方法**      | 在个股首次涨停时介入，追求次日溢价。                 | **打板**：股价封涨停后，以涨停价排队买入。 **抢板**：①股价冲涨停，卖单被吃到一半时抢入；②早盘急速冲高，在接近涨停（8%-9.9%）时买入；③涨停板打开后下杀企稳，再次回封时抢入。                      | **原则**：只做上午，尤其是10:30前更强的板。排板可能买不到，但不会亏损。                                                |
| **抢二板方法**          | 在首板后，于第二日涨停时介入，追求成为市场龙头的潜力。        | 方法与“抢首板”的三种方法完全一致，只是标的为昨日首板股。                                                                                        | **要点**：二板是定龙头的重要关口，对题材和个股地位要求更高。                                                        |
| **N字涨停战法**         | 捕捉“上涨-回调-再上涨”形态，且第二波上涨以涨停启动的个股。    | 1. 第一波上涨有涨停板，幅度不宜过大。 2. 回调过程缩量，不破关键位（如首波起涨点或重要均线）。 3. 第二波启动再次以涨停板形式开始。                                               | **买点**：N字第二笔的涨停板出现时。                                                                    |
| **市场总龙头接力战法**      | 在市场总龙头确立后，于分歧换手时介入，博弈最核心标的的持续溢价。   | 1. 标的必须是市场公认的阶段性总龙头，具有最高辨识度。 2. 参与时机多在放量换手板，而非缩量一字板。 3. 需对市场情绪周期有深刻理解。                                               | **买点**：龙头首次大分歧（放量）回封时，或次日弱转强时。 **风险**：高位博弈，对止损纪律要求极高。                                   |
| **龙头二波顶级策略**       | 针对前期总龙头，策划其二波行情的高阶策略。              | 1. 第一波上涨需具有强大号召力和人气。 2. 调整时间、幅度要足够，释放风险的同时保持股性活跃。 3. 二波启动常需新的事件或逻辑催化。                                                | **买点**：调整末端出现止跌K线组合，并伴随板块回暖或新消息刺激时。                                                     |
| **高标龙/地天板战法**      | 博弈极高位置龙头（高标）的续命，或日内极端反转（地天板）的情绪溢价。 | **高标龙**：市场最高连板股，纯情绪博弈。 **地天板**：当日从跌停拉到涨停，体现极强多头反攻和情绪逆转。                                                              | **要点**：属于高风险、高难度的极端交易模式，对盘口和情绪理解要求极高，不建议普通投资者参与。                                        |
| **暴力首板抓涨停**        | 通过特定盘口和技术形态，在首板启动瞬间介入。             | （文档中此部分内容与“打首板、抢首板”及“N字涨停”等有重叠，核心是识别强势启动的盘口特征，如大单点火、流畅拉升等）。                                                          | **买点**：结合分时攻击形态与量能，在拉升逼近涨停时介入。                                                          |
| **超短线卖法：8个点+量价背离** | 针对超短线交易的卖出纪律。                      | 1. 股价快速拉升至8个点以上。 2. 同时出现量价背离（价格上涨，但分时量峰降低）。                                                                          | **卖点**：出现“8个点+量价背离”时，可作为短线高抛信号。                                                         |


## 三、集合竞价相关战法


| 战法名称             | 核心逻辑                             | 关键量化/形态条件                                                                                                                                             | 买卖点与风控要点                                                                            |
| ---------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **集合竞价抓涨停三大模型**  | 通过9:20-9:25的竞价图，预判当日可能涨停的个股。     | **1. 一气呵成**：9:20后报价白点成水平直线，匹配量小（不超过1格），未匹配买盘（红柱）多。 **2. 缓慢上攻**：9:20后价格逐步推高，尾盘急拉，匹配量温和放大（结束小于5格）。 **3. 黄金缺口**：竞价尾盘抢筹拉升，9:25匹配量显著放大（至少4格），开盘跳空高开。       | **买点**：开盘后观察分时强度，符合预期后介入。 **选股**：从涨幅榜中筛选，剔除ST、科创板、北交所、大盘股（流通股>10亿），按成交额排序找小金额个股。    |
| **竞价抓涨停之天地乾坤战法** | 综合解读竞价10分钟的量价信息（价为天，量为地），跟随主力意图。 | 1. 识别三种竞价模型：**1大3小诱空模型**、**抢筹模型**、**大开大合洗盘模型**。 2. 理解竞价抛压会在开盘后释放，强势股会直接冲板或经1-3次试盘释放抛压。                                                                | **买点**：根据竞价模型判断强弱，在抛压释放后的拉升点介入。 **卖点**：若次日大幅高开低走，可能是一日游，应逢高出局；若小幅高开或低开高走，可能走趋势，可持有。 |
| **集合竞价一进二要点**    | 专门用于判断首板股次日能否晋级二板。               | 1. **试盘**：9:15-9:20常有拉涨停再撤单的试盘动作。 2. **抛压与承接**：9:20后，上方绿柱代表抛压，红柱代表承接。选择抛压小、承接强的。 3. **换手**：竞价匹配量达到昨日涨停“爆量”的80%-120%为佳，代表获利盘换手充分。 4. **高开幅度**：4%-6%最佳。 | **买点**：板上确认介入确定性最高。若抛压大但被强顶板上（该弱不弱），风险较高，不建议轻易追。                                    |
| **竞价弱转强/强转弱**    | 通过竞价末段未匹配量的突然变化，判断多空力量逆转。        | **弱转强**：9:20后未匹配卖单（绿柱）增多，临近结束突然变为未匹配买单（红柱）。 **强转弱**：反之，未匹配买单增多，临近结束突然变卖单。                                                                             | **作用**：作为判断当日开盘强弱的先行指标，需结合开盘后走势确认。                                                  |
| **竞价诱多/诱空识别**    | 识别主力在9:15-9:20的虚假挂单行为。           | **诱多**：9:15涨停价吸引眼球，挂大买单（红柱），卡在9:20前瞬间撤单，9:20后抛压大。 **诱空**：9:15跌停价制造恐慌，9:20后未匹配卖单（绿柱）快速被吃掉，价格拉升。                                                        | **对策**：诱多则警惕高开低走；诱空则关注低开高走可能。                                                       |


## 四、筹码分析相关战法


| 战法名称           | 核心逻辑                      | 关键量化/形态条件                                                                                                                                                                                                                                                                                                                  | 买卖点与风控要点                                                  |
| -------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **筹码峰九大跟庄战法**  | 通过筹码分布形态，直接解读主力行为，进行跟庄交易。 | 1. **单峰密集，主力参与**：低位单峰密集后放量突破。 2. **多峰林立，行情延续**：上涨途中形成多个密集峰，主力持续推高。 3. **多峰锁仓，顶级强庄**：主升浪中筹码峰稳定，量小涨停，主力锁仓。 4. **上峰锁定，上涨未尽**：上涨途中底部主力峰稳定未松动。 5. **下消上移，换庄接力**：震荡平台中，下方筹码上移，新主力接力。 6. **双峰对垒，高抛低吸**：上下两峰对峙，主力区间震荡吸筹。 7. **顶格在消，强庄在逃**：标志性顶格筹码峰开始松动消失。 8. **多峰齐消，就是要逃**：多个筹码峰同时快速消失，主力集体出货。 9. **上峰不止，下跌不止**：高位套牢峰未充分下移，下跌趋势未止。 | **核心口诀**： **“上峰不移，下跌不止”** **“下峰锁定，行情未尽”** **“双峰填谷，高抛低吸”** |
| **筹码峰看主力建仓**   | 识别主力建仓阶段及建仓峰特征。           | 1. **位置**：底部或盘整区。 2. **形态**：单峰密集，顶格，价格带窄。 3. **锁定**：形成后一段时间内形态基本不变。 4. **周期**：中线主力多为60-100周期筹码。                                                                                                                                                                                                                            | **策略**：“建仓不买”。需等待洗盘结束。                                    |
| **筹码峰看主力洗盘**   | 识别洗盘阶段及结束信号。              | 1. 发生在建仓峰锁定后。 2. 筹码峰上下产生浅色、短周期的浮筹峰，随后被清理。 3. 洗盘后呈现“筹码峰多头排列”或“仅剩底部建仓峰”的干净状态。                                                                                                                                                                                                                                                | **买点**：洗盘结束，即将启动时。信号：建仓峰锁定、上下无浮筹、放量突破主力成本区。               |
| **筹码峰看主力拉升出货** | 区分拉升与出货阶段，持股享受主升，规避顶部。    | **拉升阶段**：建仓峰上方形成新的“拉升峰”，底部峰缓慢缩短。 **出货阶段**：高位形成“出货峰”，其峰值超过底部“建仓峰”，且建仓峰明显缩短。                                                                                                                                                                                                                                                 | **策略**：“洗盘不走，出货走”。拉升阶段持股，出货阶段只卖不买，严格设置止盈线。                |


## 五、分时、盘口与量价战法


| 战法名称            | 核心逻辑                            | 关键量化/形态条件                                                                                                       | 买卖点与风控要点                                                   |
| --------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **六大分时模型**      | 将分时图归类，辅助判断当日强弱。                | （文档中列举了六种典型分时走势，如震荡上行、台阶上涨、旗形整理、钓鱼波、心电图、一字平等，每种对应不同的主力行为和市强度）。                                                  | **作用**：结合日K线位置，判断当日介入的风险与机会。例如，低位区的“震荡上行”和“台阶上涨”多为吸筹或拉升信号。 |
| **分时识主力/资金抢筹**  | 通过分时量价配合，识别主力吸筹行为。              | 1. 上涨时放量，回调时缩量，整体分时均价线向上。 2. 出现连续密集的主动性买盘，推动价格稳步上升。                                                             | **买点**：识别出主力抢筹痕迹，且股价尚未大幅拉升时。                               |
| **承接分时抄底法**     | 在下跌过程中，通过分时级别的强力承接，博弈日内反转或短期底部。 | 1. 股价分时急跌后，在某一价位反复获得支撑，跌不下去。 2. 该位置成交量显著放大，但价格不再新低，形成分时平台。 3. 随后买盘涌入，价格拉升突破分时均线。                                | **买点**：确认承接有效，并开始放量反弹时。属于左侧或逆势交易，对成功率要求高。                  |
| **分时做T法**       | 在持有底仓的前提下，利用分时波动进行日内交易，降低成本。    | 1. 通常需要个股日线趋势向上，振幅较大。 2. 在分时上冲乏力、量价背离时高抛部分仓位；在分时回踩关键支撑、跌无可跌时低吸回同样仓位。                                            | **要点**：需要较强的盘感和纪律，确保T出后能接回，避免做飞。                           |
| **板后倍量阴**       | 涨停板次日出现放倍量阴线，是一种强烈的分歧信号。        | 1. 前一日涨停。 2. 次日收阴线，且成交量至少是前一日的两倍（倍量）。                                                                           | **解读**：可能是主力出货，也可能是暴力洗盘。需结合股价位置、分时承接和后续走势综合判断，通常视为风险信号。    |
| **缩量阴线风控法**     | 上升趋势中，缩量回调是健康信号；但破位缩量阴线则需警惕。    | 1. 在关键支撑位上方缩量回调，可持股观察。 2. 若跌破重要均线或平台，即使缩量，也表明买盘力量衰弱，需风控。                                                        | **卖点**：缩量阴线跌破关键支撑位时，应考虑减仓或止损。                              |
| **缩量阳线持股法**     | 上涨过程中，缩量上涨表明抛压轻，筹码锁定良好，可继续持股。   | 1. 股价沿趋势上行。 2. 收阳线，但成交量相比前几日明显萎缩。                                                                               | **策略**：在上升趋势未破坏前，出现缩量阳线是持股信号，不必因无量而过早卖出。                   |
| **高量柱战法**       | 将成交量最大的K线视为“高量柱”，以其顶底作为攻防参照。    | 1. 高量柱当日多空交战最激烈，其收盘价和最高/最低价具有标志性意义。 2. 后续股价运行于高量柱实顶之上，为强势；运行于实底之下，为弱势。                                          | **用法**：以高量柱的实顶为攻防线（压力），实底为守防线（支撑），用于判断强弱和设定止损。             |
| **特殊量价精要**      | 总结多种特殊的量价关系组合，快速判断多空力量。         | 例如： **量增价平**：变盘征兆。 **量平价升**：持续上涨。 **量减价升**：背离风险（高位）。 **量增价跌**：出货或恐慌（看位置）。                                       | **作用**：作为K线分析的辅助工具。                                        |
| **盘口语言之精准狙击顶底** | 通过五档买卖盘挂单、成交明细中的大单，推测主力意图。      | 1. **托单**：下方有大量买单托盘却不成交，可能为护盘或诱多。 2. **压单**：上方有大量卖单压盘却不成交，可能为压盘吸筹或震慑。 3. **空中成交**：买卖档无明显大单，但成交明细连续出现大单，可能为主力对倒。 | **要点**：需结合股价位置综合判断。低位压单可能是吸筹，高位托单可能是出货。                    |


## 六、其他综合及特定形态战法


| 战法名称              | 核心逻辑                                            | 关键量化/形态条件                                                                                         | 买卖点与风控要点                                        |
| ----------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| **神奇的反转K线**       | 识别单日或双日K线组合发出的强烈趋势反转信号。                         | **单日反转**： 1. **底部**：长下影线，日内大幅探底后拉回，收盘近最高。 2. **顶部**：长上影线，日内大幅冲高后回落，收盘近最低。 **关键**：当日波幅和成交量都必须显著放大。 | **买/卖点**：底部单日反转是买入信号，顶部单日反转是卖出信号。需次日走势确认。       |
| **头肩底形态**         | 捕捉经典的中长期底部反转形态。                                 | 1. 左肩：下跌后反弹。 2. 头：再次下跌，创出新低。 3. 右肩：第二次反弹，低点高于头部。 4. 颈线：连接左肩和右肩的高点。放量突破颈线为确认信号。                    | **买点**：放量突破颈线时，或回踩颈线不破时。                        |
| **九五至尊战法**        | 通过“九五线”（紫线）和“潜龙线”（黄线）两条指标线，区分股票的平庸期与主升期。        | 1. 股价大部分时间运行于“潜龙线”和“九五线”之间，为平庸期。 2. 当股价放量突破“九五线”，意味着进入“至尊”状态，有望开启主升浪。                             | **买点**：股价站上“九五线”时，为追涨买入信号。                      |
| **重套出黑牛**         | 在板块或个股经历长期深度下跌（重套）后，寻找基本面或逻辑发生重大变化，可能走出反转牛市的标的。 | 1. 前期跌幅巨大，筹码高位套牢严重。 2. 出现行业政策拐点、技术革命、业绩爆发等根本性利好。 3. 底部开始持续放量，有新增资金入场。                             | **买点**：底部形态构筑完成，并放量突破长期下降趋势线或重要平台时。属于中长线布局策略。   |
| **蚂蚁战法（尾盘选股）**    | 在尾盘时段（如14:30后）选股，追求次日开盘的溢价，规避日内波动风险。            | （文档中未列具体量化条件，通常结合）： 1. 当日分时强势，均线上方运行。 2. 日K线处于突破位或起涨点。 3. 所属板块当日活跃。                               | **买点**：尾盘临近结束前买入。 **卖点**：次日早盘冲高卖出，严格执行隔日超短线纪律。  |
| **艾略特波浪鱼回头/突破战法** | 运用波浪理论，捕捉特定浪形（如第2浪、第4浪回调结束）的进场机会。               | **鱼回头**：对应2浪或4浪的ABC回调结束，不破1浪或3浪起涨点。 **突破战法**：对应3浪或5浪的启动突破。                                        | **买点**：鱼回头形态在C浪末端企稳时；突破形态在放量过前高时。               |
| **超跌反弹战法**        | 博弈股价短期严重超跌后的技术性反弹。                              | 1. 股价短期内连续大跌，远离主要均线，乖离率大。 2. 技术指标（如KDJ, RSI）进入严重超卖区。 3. 下跌末期出现缩量或恐慌性杀跌。                           | **买点**：出现止跌K线（如十字星、小阳线）并伴随成交量放大时。属于短线抢反弹，需快进快出。 |
| **势不可挡攻击回调战法**    | 在强势上涨趋势中，捕捉首次缩量回调至短期均线（如5日、10日）的买点。             | 1. 趋势明确向上，角度陡峭。 2. 首次出现缩量回调，触碰5日或10日均线。 3. 在均线处获得支撑，分时出现企稳迹象。                                     | **买点**：回调至关键短期均线并获得支撑时。                         |
| **神龙摆尾战法**        | 形态类似“龙回头”，但更侧重于股价在重要均线（如60日、120日年线）处获得支撑后的反转。   | 1. 股价上涨后回调。 2. 在重要的中长期均线处精准止跌。 3. 出现标志性的反转K线（如阳包阴、底分型）。                                           | **买点**：在重要均线处出现止跌反转信号时。                         |
| **三步选强庄股**        | 通过三个步骤筛选出有强庄控盘的个股。                              | （文档中未详述三步具体内容，通常包括）： 1. 形态筛选（如横盘突破、空中加油）。 2. 量能筛选（上涨放量，回调缩量）。 3. 筹码筛选（底部筹码集中，锁定良好）。               | **目的**：建立潜力股票池，长期跟踪，等待买点。                       |
| **6字买入法**         | 高度概括的买入原则，可能指六个关键买入条件或形态。                       | （文档中未列具体6字，常见如“放量、突破、拐点”等组合）。                                                                     | **核心**：将多个有效买点条件浓缩为简洁口诀。                        |
| **进击K线快速抓主升**     | 识别攻击性最强的若干种K线组合，用于在起涨点介入。                       | 可能包括：**旭日东升**、**早晨之星**、**出水芙蓉**、**多方炮**等经典看涨组合。                                                   | **买点**：进击K线组合确认形成时。                             |
| **保护线**           | 广义的止损止盈线设定方法。                                   | 可以是：**趋势线**、**重要均线**（如10日、20日）、**平台颈线**、**筹码密集峰底线**等。                                             | **用法**：股价跌破保护线，无条件执行减仓或止损。                      |
| **注册制战法之涨停回调低吸**  | 适应注册制下交易规则（如价格笼子、异动新规）的涨停股操作策略。                 | 1. 针对注册制标的（如创业板、科创板）。 2. 首个或前几个涨停后，不追高，等待回调。 3. 回调至关键位置（如5日线、涨停阳线实体内）且缩量企稳时低吸。                    | **买点**：强势涨停后的首次缩量回调买点。                          |
| **注册制→新屠龙刀战法**    | 在注册制环境下，针对龙头股的特有战法，可能更注重基本面和趋势的配合。              | （文档中未详述，可能结合了龙头战法与注册制新规下的趋势玩法）。                                                                   | **特点**：可能降低对连板高度的依赖，更注重趋势主升和逻辑兑现。               |
| **低位恐慌洗盘手法**      | 识别主力在低位通过制造恐慌进行洗盘的伎俩。                           | 1. 股价处于历史低位或相对低位。 2. 突然出现无实质性利空的放量大跌或跌停。 3. 但随后很快被收回，或次日立即强势反包，下跌区间筹码被快速锁定。                       | **对策**：识别为洗盘后，可在恐慌低点或反包确认时介入。                   |
| **均线共振手法**        | 利用多周期均线由发散转为同步向上（共振），产生的强大助推力。                  | 1. 短、中、长期均线（如5、10、20、60日）由粘合转为一致多头发散。 2. 股价放量站上所有共振均线。                                            | **买点**：均线系统形成共振多头排列，且股价放量启动时。                   |
| **精准找买卖点之量价关系篇**  | 系统性地运用量价关系理论来确定买卖时机。                            | 涵盖“量增价涨”、“量缩价跌”、“量平价平”等多种组合在不同位置的含义，形成决策系统。                                                       | **核心**：量在价先，通过成交量的异动和变化，预判价格的走向。                |
| **一根线抓牛股起爆点战法**   | 通过某一根特定的、具有标志性意义的K线，来确认牛股启动。                    | 这根线通常是：**放量涨停板**、**放量突破大阳线**、**突破长期趋势线的大阳线**等。                                                    | **买点**：标志性K线出现的当日或次日确认时。                        |
