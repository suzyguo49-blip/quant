# 交易系统宪法（最高优先级）

> 修改需用户明确确认，并在 `changelog.md` 记录原因。

## 市场与周期

- **市场**: A 股个股（不含北交所除非另行注明）
- **主策略**: **月度主线 + 龙头**（`playbooks/theme.md`，setup_tag: `monthly_theme_dragon`）
- **原则**: 无合格主线 → **空仓**；有主线 → 仅持龙头 **1～2** 只
- **数据**: `stock_data.db` 日线；实盘以收盘后信号为准

## 资金与风险

| 条款 id | 内容 |
|---------|------|
| C-001 | 单笔最大亏损不超过总资金的 **2%** |
| C-002 | 同时持仓不超过 **5** 只（默认策略） |
| C-005 | **月度主线策略**下同时持仓不超过 **2** 只（龙头） |
| C-003 | 当日亏损达 **3%** 停止开新仓 |
| C-004 | 禁止满仓单票 |

## 禁止清单

| 条款 id | 内容 |
|---------|------|
| C-101 | 不买 ST（`isST=1`） |
| C-102 | 不买上市未满 60 日新股（除非 playbook 特批） |
| C-103 | 不逆势加仓亏损仓 |
| C-104 | 入选标的须 **PE(TTM) < PE(静)** 且二者 > 0 |

## 执行原则

- 计划内交易才下单；盘中临时想法记入 journal，次日再评估是否入 playbook
- 所有成交必须写入 `trades.csv`
