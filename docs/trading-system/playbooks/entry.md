# 入场规则（Entry）

> **默认实盘逻辑**：`playbooks/theme.md`（月度主线龙头）。  
> 细则与代码见 `monthly_theme_dragon.py`。  
> **次日怎么买**：见 **E-009**（全策略共用执行窗口）。

### E-009 次日执行窗口（全策略共用）

- **setup_tag**: `execution_window`
- **信号确认**：信号日 **收盘** 判定（各策略 N-xxx / T-002b 等）
- **执行日**：**次日**；**禁止** 9:30–10:30 追买（开盘震荡区）
- **买入时间窗**：**10:30–11:00** 或 **13:00–14:30**；14:30 前未成交 → **当日放弃**
- **限价参考**：信号日收盘价 **−1%～+2%**；**高开 >3%** → 放弃（不追）
- **T+1 换仓**：需换仓时 **上午先卖**（9:35–10:30）破线/计划减仓仓 → **10:30 后再买**
- **试仓**：新开仓可先 **50% 槽位**，次日仍符合 playbook 再加满
- **条件单**：券商设限价/触发单，参数见日报 **第十节 次日执行清单**
- **止损**：仍按各策略 R-001 / R-003；T+1 下止损最早在 **买入次日** 执行
- **版本**: v1 | 2026-06-14
- **状态**: active
- **代码**: `scripts/trading/briefing_execution.py`；日报第十节

- **setup_tag**: `monthly_theme_dragon`

- **止损**: `risk.md` R-003
