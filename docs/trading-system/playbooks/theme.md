# 月度主线 + 龙头（核心策略）

> **主策略**：无合格主线时空仓；有主线时 **尽量持仓**（T-002c 龙头建仓 + T-002b 回调优先），不追高。  
> **节奏**：**每个交易日收盘后 `scan`** → 决定 **次日 10:30 后** 是否开仓（E-009；不盘中追涨）。  
> **代码**：`monthly_theme_dragon.py`  
> **setup_tag**：`monthly_theme_dragon`

---

## 一、概念定义

| 术语 | 定义 |
|------|------|
| **月度主线** | 某一行业/板块形成持续赚钱效应；**激活**用近 5 日强确认（T-001），**退出**仍参考更长周期（T-004） |
| **5 日强确认** | 最近 **5** 个交易日：上涨日 **≥ 4**，累计涨幅 **≥ 4%**，成交额放大 |
| **龙头池** | 主线内按强度排名的候选（观察名单） |
| **可买·回调** | 龙头池满足 **T-002b** 真回调 |
| **可买·建仓** | 主线激活但无回调时，按 **T-002c** 买龙头（≤2 只） |
| **空仓** | 无合格主线；或主线激活但龙头池当日均不可买（大涨/大跌） |

## 二、规则条目

### T-001 主线激活（5 日强确认）

- **setup_tag**: `monthly_theme_dragon`
- **条件**（须同时满足）:
  1. 板块内有效 A 股 ≥ 5 只（非 ST、非指数、上市满 60 日）
  2. 近 **5** 个交易日，板块等权日收益 **上涨天数 ≥ 4**
  3. 板块 **5 日累计涨幅 ≥ 4%**
  4. 板块 5 日平均成交额 ≥ 其 60 日均值的 **1.1** 倍
- **版本**: v3 | 2026-05-17
- **状态**: active

### T-002a 龙头池（观察）

- **setup_tag**: `monthly_theme_dragon`
- **条件**（在 T-001 激活板块内）:
  1. 收盘价 > 20 日均线；非一字涨停（振幅 > 0.5%）
  2. 按强度得分排名取前 **5** 只（20 日涨幅 + 成交额 + 换手率）
- **动作**: 列入 **观察**；无 T-002b 时由 **T-002c** 择强建仓
- **版本**: v2 | 2026-05-17
- **状态**: active

### T-002b 真回调买入（过滤假回调）

- **setup_tag**: `monthly_theme_dragon`
- **条件**（在 T-002a 池内，**须全部满足**）:
  1. 当日涨幅 **< 5%** 且 **> -2%**（不大涨、不大跌；大跌日视为下跌中继）
  2. 收盘相对 20 日线乖离 **1%～9%**（`0.01 ≤ ma_bias < 0.09`，避免贴 MA20 假突破）
  3. **近 5 日收益率 ≤ -1.0%**（须有一定幅度回调，非「微跌一天」）
  4. 收盘价 **> MA10** 且 **> MA20**（短期趋势未坏）
  5. 仍满足 T-002a 基础过滤
- **入场**: 仅对 `scan` 标记为 **【可买】** 的标的；**信号日收盘判定，次日开盘执行**；最多 **2** 只
- **禁止**: 当日大跌抄底、贴 MA20 买入、悬空远离均线
- **版本**: v3.1 | 2026-05-17
- **status**: active
- **代码**: `monthly_theme_dragon.py` → `candidates_buy`（`signal=buy`）

### T-002c 主线建仓（尽量每日持仓）

- **setup_tag**: `monthly_theme_dragon`
- **条件**（在 T-002a 池内，**须全部满足**）:
  1. 当日涨幅 **< 5%** 且 **> -2%**
  2. 收盘相对 20 日线乖离 **< 9%**
  3. 收盘价 **> MA10** 且 **> MA20**
  4. **不要求** 近 5 日回调（与 T-002b 区分）
- **优先级**: 先填满 T-002b 回调标的，不足 `max_dragons` 时按龙头强度得分补 T-002c；池内均大涨则当日不新开
- **入场**: 与 T-002b 合并为 `dragons_buy`；最多 **2** 只
- **版本**: v1 | 2026-05-17
- **status**: active

### T-003 唯一主线（择强）

- **条件**: 若同日多个板块满足 T-001：
  1. **优先**在 `manual_themes.yaml` 人工题材池中，取 **5 日涨幅最高** 的一条作为交易主线
  2. 若无人工题材激活，再取 Baostock **行业** 板块中涨幅最高者（较宽，仅作兜底）
  3. 行业板块涨幅更高时 **不覆盖** 人工主线，可在日报中作「行业参考」
- **动作**: 不在次要板块开仓
- **版本**: v3 | 2026-05-24
- **状态**: active

### T-003b 支线龙头（观察）

- **条件**:
  1. 同日多个 **人工题材** 满足 T-001 时，取 **5 日涨幅第二** 的题材为支线
  2. **弱支线兜底**：若仅一条人工题材过 T-001，取次强人工题材（5 日涨幅 ≥ **2%**、上涨日 ≥ **3**），标注「未达 T-001」
- **动作**:
  - 扫描/日报输出支线龙头池（T-002b/T-002c 规则与主线相同）
  - **不参与** 主线 Dragon 自动开仓优先级；供观察、换仓、与持仓对照
  - 若仅行业板块激活、无第二人工题材，则无支线
- **版本**: v1 | 2026-06-02
- **状态**: active

### T-004 强制空仓

- **条件**（任一）:
  1. 无任何板块满足 T-001 → 清仓（**须满足 T-005 最短持有**）
  2. 有主线但 **T-002b / T-002c 均无可买标的**（龙头池当日均大涨/大跌）
  3. 持仓龙头收盘价 < **20** 日均线（X-003，**随时**，不受 T-005 限制）
  4. 所属板块近 20 日上涨日 < **10**（长线走弱）
  5. 触发 constitution C-003
- **动作**: 清仓或不开新仓
- **version**: v3 | 2026-05-17
- **status**: active

### T-005 最短持有（防闪卖）

- **setup_tag**: `monthly_theme_dragon`
- **条件**: 买入后未满 **3 个交易日**
- **动作**:
  - **禁止** 因单日 `theme_off` 卖出（满 3 日前）
  - **仍允许** R-003 止损（**-5%**）与 X-003（破 **20** 日线）
- **版本**: v2 | 2026-05-17
- **状态**: active

### T-006 持仓不因「掉出可买池」卖出（已取消 drop_dragon）

- **setup_tag**: `monthly_theme_dragon`
- **规则**: 持仓后 **不再** 因当日不在【可买】/ `dragons_buy` 列表而卖出
- **仍卖出**: X-003 破 MA20、R-003 止损 -5%、T-004 主线 `theme_off`（满最短持有后）
- **版本**: v1 | 2026-05-17
- **状态**: active

## 三、每晚 scan → 次日执行

| 步骤 | 时间 | 动作 |
|------|------|------|
| 1 | 收盘后 | `python dataScrapper.py daily`（若已定时可跳过） |
| 2 | 收盘后 | `python monthly_theme_dragon.py scan` |
| 3 | 当晚 | 阅读日报 **第十节 次日执行清单**；可设条件单 |
| 4 | 次日 | 仅执行【可买】；**10:30 后**按 E-009 限价买；无【可买】则不动 |

| scan 输出 | 当晚结论 | 次日操作 |
|-----------|----------|----------|
| 无合格主线 | 空仓 | 不买入；持仓按 exit 处理 |
| 有主线 + 仅【观察】 | T-002c 建仓或等回调 | **10:30 后**按【可买·建仓】/【可买·回调】买入（E-009） |
| 有主线 + 【可买】 | 列入执行清单 | **10:30 后**买入 ≤2 只（E-009） |

`scan` 末尾会打印 **【次日策略】** 摘要。

## 五、参数（ThemeConfig）

| 参数 | 值 | 说明 |
|------|-----|------|
| `window_days` | 5 | T-001 窗口 |
| `min_up_days` | 4 | 5 日中至少 4 日上涨 |
| `min_sector_return` | 0.04 | 5 日累计涨幅 ≥ 4% |
| `amount_ratio` | 1.1 | 5 日均额 / 60 日均额 |
| `max_daily_pct_chg` | 5.0（%） | T-002b |
| `max_ma_bias` | 0.09 | T-002b |
| `min_ret5` | -0.01 | 5 日至少回调 1.0% |
| `min_entry_pct_chg` | -2.0 | 当日跌幅不超过 2% |
| `min_ma_bias` | 0.01 | 明显高于 MA20 |
| `require_above_ma10` | true | 站上 MA10 |
| `require_daily_position` | true | T-002c 主线尽量持仓 |
| `pool_watch_size` | 5 | 观察池 |
| `max_dragons` | 2 | 最多持仓 |
| `min_hold_days` | 3 | T-005 最短持有 |
| `stop_loss_pct` | 0.05 | R-003 止损 -5% |
| `ma_exit` | 20 | X-003 趋势出场 |
